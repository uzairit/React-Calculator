# 🧮 React Calculator

A simple **React-based Calculator** project built using functional components and React hooks (`useState`).  
This project demonstrates **state management, component reusability, event handling**.

---

## 🚀 Features
- Basic arithmetic operations: `+`, `-`, `/`, `*`
- Clear (`C`) button to reset input
- Responsive and clean UI

---

## 🛠️ Tech Stack
- **React** (Vite + JSX)
- **JavaScript (ES6+)**
- **CSS** (for styling components)
